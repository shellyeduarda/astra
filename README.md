ASTRA 

O ASTRA é um site desenvolvido com o objetivo de apresentar conteúdos sobre exploração espacial de forma moderna, visual e acessível.

O projeto aborda temas como NASA, missões espaciais, foguetes, planetas, astronautas e imagens relacionadas ao universo.

|Tecnologias utilizadas|

- HTML
- CSS

|Funcionalidades|

Site responsivo para computador e dispositivos móveis
Navegação entre diferentes áreas sobre exploração espacial
Painel administrativo para edição de conteúdos
Interface inspirada em exploração espacial

|Páginas|

- Início
- NASA
- Missões
- Foguetes
- Planetas
- Astronautas
- Galeria

|Acesso ao projeto|

O site está publicado através do GitHub Pages.

|Sobre o desenvolvimento|

Este foi meu primeiro projeto de site. Durante o desenvolvimento, utilizei ferramentas de IA como apoio no aprendizado, na compreensão do código e na implementação de algumas funcionalidades.
